Лабораторная работа №1

Анализ данных: Medical Cost Personal Dataset

1. Описание проекта

В данной лабораторной работе выполнен анализ набора данных Medical Cost Personal Dataset. Датасет содержит информацию о возрасте, поле, индексе массы тела, количестве детей, курении, регионе проживания и расходах на медицинскую страховку.

Исходный набор данных содержал 1338 записей и 7 столбцов.

2. Описание переменных

Переменная| Тип данных| Описание
age| int64| Возраст
sex| category| Пол
bmi| float64| Индекс массы тела
children| int64| Количество детей
smoker| category| Наличие курения
region| category| Регион проживания
charges| float64| Расходы на медицинскую страховку

3. Используемые библиотеки

- Pandas — загрузка и обработка данных.
- Matplotlib — построение графиков.
- Seaborn — визуализация данных.

4. Предобработка данных

В ходе работы были выполнены следующие действия:

1. Загружен CSV-файл с помощью Pandas.
2. Изучена структура таблицы и типы данных.
3. Проверены пропущенные значения. Они отсутствовали.
4. Обнаружена и удалена одна дублирующаяся запись.
5. Столбцы sex, smoker и region преобразованы в категориальный тип данных.

После обработки датасет содержит 1337 записей и 7 столбцов.

5. Визуализация данных

Построены три графика:

1. Распределение расходов на медицинскую страховку.
2. Зависимость расходов от возраста с разделением по признаку курения.
3. Сравнение расходов на страховку среди курящих и некурящих людей.

6. Результат работы

В результате лабораторной работы выполнена загрузка, проверка и предобработка данных, а также построены графики для анализа расходов на медицинскую страховку.
